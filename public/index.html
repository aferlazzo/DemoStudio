Start demoMaker from its launcher

This HTML file cannot run the recorder by itself. The local server loads the controls and converts recordings to MP4.

  1. Open the demoMaker folder in File Explorer.
  2. Double-click Start Demo Studio.cmd.
  3. Keep its terminal window open. The working studio opens automatically in your browser.

If the launcher is already running, open the running studio →.
